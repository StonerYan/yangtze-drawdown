# yangtze-drawdown

Code and derived datasets for the study **"Upland Greening and Reservoir Drawdown-Zone Greenness in the Yangtze Basin"**.

## Repository Structure

- `analysis/`: Statistical analysis scripts (`r1_core.py` – `r8_round2.py`, `facts.py`, `common.py`) covering trend estimation, counterfactual bounds, long-term Landsat/MODIS comparisons, daily storage-based subaerial exposure modelling, and spatial/inundation-band stratification.
- `figures_code/`: Plotting scripts (`fig01_concept.py` – `fig08_exposure.py`, `fig_ga.py`, `run_all_figures.py`) to reproduce Figures 1–8 and the Graphical Abstract in both PNG (600 dpi) and PDF formats.
- `data/`: Derived datasets used by the analysis and figure scripts (`cee/`, `cee2/`, `cee_wet/`, `derived/`, `pilot/storage_52_csv/`).
- `results/`: Pre-computed intermediate JSON/CSV outputs generated by `analysis/` and consumed by `figures_code/`.

## Requirements

- Python >= 3.10
- `numpy`, `pandas`, `scipy`, `matplotlib`, `cartopy`, `shapely`, `scikit-learn`, `statsmodels`, `pyarrow`

## Usage

1. Reproduce all figures from pre-computed results:
   ```bash
   cd figures_code
   python run_all_figures.py
   ```
2. Re-run individual analysis modules (optional, overwrites `results/`):
   ```bash
   cd analysis
   python r1_core.py
   ```
